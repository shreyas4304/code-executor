# Code Execution Platform

A scalable backend system to execute user-submitted code securely using Docker and Redis.

## Tech Stack
- Java
- Spring Boot
- Redis
- MySQL
- Docker
- AWS 

## Features
- Execute code securely in Docker containers
- Redis-based queue for handling concurrent requests
- Worker-based async processing
- Store execution results in MySQL
- REST API design

## Future Improvements
- Multi-language support
- Rate limiting
- Kubernetes deployment
